How to add a note to this site

Notes are plain HTML pages. Copy this one, change the words, and link to it from the Writing list on the home page.

Published
24 November 2026
Kind
Guide
Reading time
3 minutes

Make the page

  1. Copy writing/example-note.html and rename the copy. Use lowercase words joined by hyphens, because the file name becomes the address: writing/entra-sso.html.
  2. Change the <title> and the description at the top of the file. They show in search results and link previews.
  3. Replace the title, the facts and the text. Everything you need is in the HTML elements already on this page.

Link to it

Add a row to the Writing list in index.html, newest first:

<li class="row">
  <h3 class="row__title"><a href="writing/entra-sso.html">Your title</a></h3>
  <p class="row__when"><time datetime="2026-12">Dec 2026</time></p>
  <span class="socket" aria-hidden="true"></span>
  <p class="row__meta">Guide, 8 minutes</p>
</li>

What you can use

Long-form pages are styled for the usual writing elements, so you can use them as they are.

ElementUse it for
h2, h3Sections and subsections
ul, olLists and numbered steps
pre and codeCode blocks and inline code
blockquoteQuotes
figure and figcaptionImages, diagrams and video, with a caption
aside class="callout"A tip or a warning

Tip: titles that say what the reader will be able to do get read. “Getting live call transcripts into ticket fields” does more work than “Thoughts on transcription”.

Images and video

Put image files in assets/img/ and always write alt text that says what the image shows. For a video, put the player inside a figure and add a caption that says what it covers and how long it runs.
